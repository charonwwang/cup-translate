# 设置布局、历史记录与 JSON 配置迁移（2026-10-16）

## 产品决定与实现

- 设置页固定侧栏与标题栏，由内容区统一负责滚动；补齐 flex/grid 高度约束，隐藏滚动条，保留触控板、滚轮和键盘滚动。切换路由回到顶部。
- 语音策略改为独立卡片：标题/说明和选择器分区，窄窗口上下排列。移除同一 flex 行里挤压长说明的布局。修复代理双输入框被挤压；统一服务添加按钮与焦点样式。
- 历史详情值得提供复制与朗读：回看旧译文时无需重新翻译。原文、译文分别有复制/朗读/停止。默认只读，普通文本可显式编辑；词典 JSON 转为可读释义，避免意外改坏结构化记录。朗读沿用全局语音策略，关闭详情即停止。
- 独立云备份页退出侧栏与路由，旧 /backup 跳转常规设置。原云备份代码及既有远程备份没有删除。
- 常规设置底部新增配置迁移卡：导出/导入 JSON。文件带格式标识与版本，包含偏好/服务配置；不包含历史、插件文件、离线模型文件。
- 导出默认省略常见密钥/密码/令牌字段，用户可勾选以明文包含。导入合并同名设置，未提供的设置和密钥保留。
- 导入先校验并展示配置项数量，再点击应用；限制 2 MiB、深度/项数、危险对象键、服务列表/热键类型和端口范围，检查与现有设置的类型兼容性（端口兼容字符串/数字）。只保存一次，失败尝试恢复原快照。导入后提供重启入口，完整应用热键/网络等设置。

## 验证

- pnpm check 通过：Vite 生产构建与 405 项测试。
- 新测试覆盖：JSON 往返、默认省略与显式包含凭证、合并保留密钥、危险键/畸形/超大输入拒绝、类型不匹配不写入、保存失败回滚及新增键清除、端口兼容性、历史词典 JSON 显示。
- 实际 React 页面隔离夹具验证：880×600 文档中滚动区域 clientHeight=554、scrollHeight>1500、scrollbar-width=none；能滚动至底部导出，校验导入并完成，显示重启提示。
- 实际历史详情点击复制、朗读后显示停止按钮，再次点击停止。该 UI 验证使用静音 PCM 和内存剪贴板，未读写用户配置或历史。
- 截图：settings-speech-layout.png、settings-json-transfer.png、history-detail-actions.png，均位于 docs/design/ui-review-v3/screenshots/。

## 约束

- 配置迁移不是全量数据备份，不携带插件或模型二进制。
- 单元测试验证配置回滚逻辑；不可恢复的存储硬件错误仍可能导致保存失败。
- 浏览器夹具中的文件对话框与磁盘操作在内存模拟；本轮没有覆盖安装客户端中的原生文件对话框人工验收。
