# 词典操作、语音路由、权限与热键（2026-10-16）

## 修复与行为

- 词典结构化结果不再禁用朗读/回译：对实际释义提取文本，不把 noun 等词性标签作为朗读内容。回译成功展示文本，返回译文恢复原词典视图。
- 默认语音策略改为跟随引擎：Google → Google TTS，Lingva → Lingva TTS；其他缺少已接入语音接口的在线引擎明确使用 Google。没有假设所有翻译 API 都提供语音。
- 本地模型自动策略只选择已配置的 local_tts；没有本地语音时提示独立配置，结果卡支持显式选择 Google 或本地语音。设置 → 服务 → 语音合成也可统一指定 Google、本地或原服务列表首项。
- 原文默认 Google，允许通过全局策略切换。Google TTS 原模块缺少 Language/Config/服务名元数据，导致调用/设置不完整，现补齐。未支持的语言不再偷偷回退英语。
- 启动只静默检查 macOS 辅助功能权限；热键设置提供状态检查及用户主动授权按钮。普通翻译和朗读不需要此权限。
- 当前本地构建的签名检测结果为 linker-signed ad-hoc、无 TeamIdentifier，重编译可能影响授权身份。此修复消除主动启动弹窗，不能让 macOS 自动信任新二进制。没有重置 TCC、修改系统授权或伪造签名。
- 录入时即时检测本软件内快捷键重复（归一化修饰键顺序/别名），阻止保存。
- tao 0.16.10 的 macOS 热键实现丢弃 Carbon 注册错误并返回 Ok，导致占用时误报成功。现增加原生 Carbon 临时注册预检；失败保留旧绑定。确认时仍走现有注册与回滚。其他软件的非独占按键监听、部分系统保留行为无法完整检测，设置页明确说明。

## 验证

- 前端 399 项通过；Rust 155 项通过，1 项本地模型基准忽略。
- Rust 在 macOS 使用 Carbon 注册组合，再验证预检拒绝该已占用组合；覆盖虚拟键码。
- Google 朗读实际请求自编测试句，HTTP 200、15168 字节，afinfo 验证 MPEG3 单声道 24kHz、1.896 秒。不使用用户输入。
- 浏览器隔离夹具验证词典按钮可用、回译并返回词典、重复热键即时提示且不能确认。夹具不注册真实快捷键、不读写用户配置。
- 截图：docs/design/ui-review-v3/screenshots/dictionary-actions-enabled.png、hotkey-conflict-inline.png。

## 限制

- 预检释放到正式注册间存在系统层竞态，旧 tao 后端不能彻底保证最终注册的返回值真实；其他进程恰在此间抢占属于残余风险。
- macOS 预检覆盖普通字母/数字、常见标点、F1–F12、导航键；未映射按键明确拒绝，避免假报成功。
- 浏览器夹具验证界面，不替代原生客户端人工听感及跨重启授权持久性验收。
