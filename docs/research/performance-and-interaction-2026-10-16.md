# 交互、性能与本地翻译修正记录 · 2026-10-16

本轮围绕输入、快捷键、启动加载、在线请求与本地推理处理可验证的问题。没有更换模型权重，也没有把所有翻译提供商逐个升级。之前的 UI 重构仍保留。

## 已落实

| 范围 | 问题与处理 |
|---|---|
| 输入 | 文本框增加左右 12px、上下 9px 内边距；IME 组合输入时 Enter 不触发翻译；变量名转换改用 React 键盘事件，移除没有清理的原生监听；初始化原文只读取一次，配置变化不再回填旧原文 |
| 快捷键 | 划词默认 Alt+T，剪贴板默认 Alt+Shift+T；保留用户已经保存的自定义/禁用值。录制仅改草稿，Esc 撤销、确认后才注册和保存；聚焦不解绑。后端显式新值覆盖旧配置，注册失败保留旧配置与回滚路径；启动时某个绑定失败仍继续尝试其他绑定 |
| 加载 | 各窗口与八个设置分区按需加载；本地语言检测预热移出启动主路径，检测命令本身也在阻塞池执行 |
| Google | 相同在途请求合并；最多 32 条、有效期 2 分钟的内存 LRU 缓存，不缓存错误；缓存键区分文本、语言和自定义端点。单次 HTTP 6 秒，最多 3 次，退避 250/500ms；4xx（429 除外）不重试 |
| 请求状态 | 请求编号改为组件自己的 ref，卸载或切换输入使旧结果失效，避免使用列表索引共享请求状态 |
| 本地模型 | 前端与后端默认统一为 2 线程；按实际语向检查已安装模型；解码与加载放入阻塞池，通过异步锁串行控制推理；模型加载去重；参数变化先释放缓存旧项；空闲约 120–150 秒释放无在途引用的缓存；提供手动释放模型内存入口，不删除模型文件 |
| 下载 | 两个方向都固定仓库提交版本与内容 SHA256；临时文件下载并验证后原子改名，避免半个文件被判为已安装 |
| 效果 | 英译中的语言标记从强制目标前缀修正为源 token 首位；长文本在句子/词边界分段并保留段落；快速/均衡/更多搜索分别 beam 1/2/5，默认仍为 2；输入不含私用字符而输出出现私用字符时回退一次更宽搜索 |

Google 重试参数相加为 18.75 秒上限预算，不把它当作包含系统调度、DNS、native 开销的硬实时保证。缓存不会写入磁盘。按需加载减少入口体积，不等于减少整个安装包大小或按同一比例加快启动。

## 真实模型基准

环境：Apple M6，macOS 27.0.1，arm64；项目锁定版本的 ct2rs/CTranslate2；int8 en→zh，2 线程。固定 10 个自写英文样例，每个模式顺序运行一次。没有标准语料评分，没有把 10 句样例外推为通用质量提升；中译英本轮只做配置和下载完整性修正，未运行质量基准。

| 模式 | 平均 ms/句 | 中位 ms/句 |
|---|---:|---:|
| 快速（包含异常输出回退） | 36.38 | 40.65 |
| 均衡（默认） | 38.08 | 34.06 |
| 更多搜索 | 61.58 | 57.39 |

本次模型构造约 70.85ms，文件可能已在系统缓存中，不能视为冷启动指标。整个独立基准进程峰值 RSS 为 191,791,104 字节，约 183 MiB，**不是完整客户端的内存占用**，也不是空闲释放后的节省量。更改线程数和两个语向共存会改变内存。释放缓存会丢弃模型对象，但分配器/系统可能保留部分内存，不保证 RSS 立即下降至固定值。

同模型、同 beam 2 的具体变化：

| 原文 | 原先将语言标记放在目标前缀 | 修正为源 token 前缀 |
|---|---|---|
| She carefully documented the intermittent memory leak before filing the bug report. | 她在提交错误报告前仔细记录了间歇性内存漏漏出的情况。 | 她在提交错误报告前仔细记录了间歇性内存泄漏。 |
| Version 3.0.7 fixes 12 issues and uses 2 worker threads. | 第3.0.7版第3.07版为12期订了12期,使用2条工人线。 | 版本3.0.7处理12个问题,使用2个工人线。 |

第二句仍把 worker threads 译成“工人线”，说明技术术语质量仍有限。beam 5 的“Hello, world.”仍会产生“哈罗,世界。”，因此没有默认启用更宽搜索，也没有用清洗文本去掩盖模型错误。

完整样例、修正前后输出、耗时与内存数据见 [JSON](performance-and-interaction-2026-10-16.json)。可重复运行：准备通过文件校验的模型目录，执行 `cargo test --release benchmark_local_model -- --ignored --nocapture`（在 src-tauri 中运行，并设置 `CUP_MT_MODEL_DIR`）。普通测试不下载模型、不运行这个基准。

## 下载修复的依据

从 Hugging Face 原站 API 查询到的提交版本，并按该版本下载文件、计算内容 SHA256；没有关闭校验或信任镜像返回的新哈希。

- [en→zh 固定版本](https://huggingface.co/jiangzhuo9357/opus-mt-en-zh-ct2/tree/06fb49e2f6cb0485043ae703a4c2afddd4e700d7)
- [zh→en 固定版本](https://huggingface.co/jiangzhuo9357/opus-mt-zh-en-ct2/tree/b9f5527123795289acc264489cbd4927801601d7)
- [原始 OPUS 模型说明](https://huggingface.co/Helsinki-NLP/opus-mt-en-zh)：要求句首目标语言标记。实际实现将标记加入编码后的源 token 序列，避免被 SentencePiece 当成普通文本拆分。
- [CTranslate2 参数说明](https://opennmt.net/CTranslate2/python/ctranslate2.Translator.html)：源长度限制可能截断输入；beam 是搜索宽度，不能直接等同于质量。本项目实际参数以已安装的 ct2rs 0.10.1 源码为准。

## 构建与验证边界

- 393 项 Node 测试通过，Rust 152 项通过；另一个需要真实模型的基准测试单独执行成功。
- 前端构建后入口 JavaScript 为 443,278 字节（gzip 129,291）；之前约 2.19 MB。各动态窗口/页面仍会按需读取其他 chunk，不能将入口差值当作总资源减少量。
- 使用实际 React 组件与内存 IPC 替身检查了输入 12px 留白、快捷键草稿/取消/保存、两个绑定独立保存、按需页面切换。截图在 `docs/design/ui-review-v3/screenshots/`。
- 最终尝试打开新原生客户端时，工具报告 Mac 已锁屏且无法自动解锁。原生系统快捷键、选区读取、失焦行为仍需解锁后在真实 macOS/X11/Wayland 集成验收；本轮没有以浏览器模拟替代这些平台级结论。没有覆盖用户的已安装客户端或修改用户模型配置。
