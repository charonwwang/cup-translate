交互逻辑改动
1. 源文块是唯一可编辑焦点，其余全部只读；点击译文自动全选该段。
2. 语言条与源文同宽、紧贴其下，交换按钮居中；「翻译」按钮只在输入态出现（自动翻译时可以省掉）。
3. 每个引擎一张结果卡，首位引擎为主角（描边+更大字号），失败/未配置不再展开空卡片，只留一行状态。
4. 卡片上的操作默认隐藏，hover 才出现，静默态更干净。
5. 底部操作条固定，不随内容滚动；关闭/置顶等窗口级操作上移到标题栏。
与现有实现的对应关系
· 源文块 ← SourceArea；语言条 ← LanguageArea；结果卡 ← TargetArea（拖拽排序保留，手柄放在卡片标题栏）。
· 现有 hide_source / hide_language 开关可直接映射为「隐藏源文块」「隐藏语言条」。
· 置顶/关闭仍调用同一批 appWindow API，只是换了位置与样式。

状态栏渲染样式

对应设置页里的 statusBar 风格选项。三种风格共用同一份样式令牌，切换时不会跳色。
