会保证

  • 模型未安装时不会出现在可选结果里，也不会发空请求。
  • 本地服务失败不自动回退；全局“仅在设备处理”同时约束检测、翻译、OCR 与朗读。
  • 术语命中后，输出使用用户设定的固定译法。
  • API Key 不进配置导出、日志或普通配置文件。
  • 卸载模型会释放磁盘；正在使用的任务先取消。

不会承诺

  • 本地小模型的流畅度一定优于在线大模型。
  • 术语替换后整句语法、语序和语气一定完美。
  • 一个 80 MB 模型能覆盖所有语言或所有专业领域。
  • 所有 TTS 引擎都支持音素级发音词典。
  • 自定义 API 一定支持流式、风格指令或术语约束。

失败时

  • 下载失败：保留已下载分片，切换镜像，显示可重试原因。
  • 模型损坏：哈希校验失败即停用并要求重新下载。
  • 内存不足：释放空闲模型；仍不足则建议换模型。
  • 自定义 API 超时：显示地址、状态码与重试，不重试 POST 风暴。
  • 语言不支持：明确提示，提供在线引擎或新增模型方向。

本地模型的用户可见状态

未安装 → 下载中 → 校验中 → 预热 → 就绪 → 空闲释放 → 再次加载 ↘ 失败 / 可重试
设计原则：技术复杂度留在编排层，界面只问“你要做什么”。任何下载、联网、隐私边界与模型许可都在动作前可见。 原型中的体积、内存和平台信息用于展示交互，实际以设备检测和模型目录为准。
