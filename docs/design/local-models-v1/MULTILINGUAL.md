用户追加实施范围：模型中心先选模型系列，再选规格或音色。此要求覆盖原 v2 对 HY-MT 和新增本地 TTS 的延期决定。既有配置与默认服务不重置。

## 翻译

HY-MT1.5 1.8B 使用 Tencent 官方 GGUF，通过内嵌 llama.cpp CPU 推理，不需要 Python、Ollama 或外部服务。

| 规格 | 权重下载量 | 选择建议 |
|---|---:|---|
| Q4_K_M | 1,133,080,512 字节 | 默认推荐，建议整机至少 8 GB 内存 |
| Q8_0 | 1,908,528,288 字节 | 空间更充裕时选择，建议至少 12 GB 内存 |

内存为选型建议，并非峰值占用保证。运行时 CPU 线程上限 8，权重 mmap；切换规格时释放闲置的另一规格，闲置约 2 分钟后卸载缓存。长文本按 500 字分段，推理可取消，超过上下文或输出限制明确报错。

同一规格支持多语言互译，不按语言对另下载。界面语言选择控制每次输入和目标语言，包括简繁中文；自动识别出错后手动切换会产生新请求。未支持方向提前过滤。模型管理中的规格选择不会替换当前原文或目标语言。

固定来源：`tencent/HY-MT1.5-1.8B-GGUF`，revision `265b2e615a7dc9b06c435dc878829ad99a512ba2`。各文件 SHA256 在原生 manifest 与安装详情中。许可证为 Tencent Hunyuan Community License，随模型下载 `License.txt`；不标成 Apache/MIT。

安装沿用固定文件清单、限量下载、断点任务、完整校验、真实推理自检和原子发布。可选择下载目录镜像地址或导入兼容目录；导入必须符合该规格的固定文件及校验和，并非任意 GGUF 都能运行。卸载只移除所选规格；保留服务配置与历史，重新安装后可继续使用。

## 朗读

Kokoro v1.0 82M INT8 使用 sherpa-onnx 1.13.8 官方共享 CPU 运行时。一个 132,303,094 字节的压缩包包含共同 ONNX 权重、音色表和语言处理数据；无需每种语言下载一套权重。

本版本开放并实际合成验证：中文普通话、英语、法语、西班牙语、意大利语、巴西葡萄牙语、印地语，共 49 个音色。葡萄牙语音色采用巴西口音；繁体中文使用普通话音色。日语处理链路未完成验证，本次不开放，不能据模型宣传直接当作支持。

音色语言筛选只配置偏好，原文与译文各自按文本语言路由。不能把中文音色用作英文音色。缺少对应语言时提示，不回退 Google。安装后全程本地合成，每次最多 3000 字；“停止”会停止播放和丢弃过期结果，已经进入原生合成的计算仍可能继续到当前请求结束。

安装前“试听样例 · 联网”下载固定公开音频，不发送待翻译文本；安装后“本地试听”真实合成。下载支持进度、取消、重试，重试可复用完整且校验正确的压缩包，部分下载重新开始。解压拒绝越界路径、链接与未列入 manifest 的文件，逐文件校验后再真实合成自检，成功才发布。卸载删除共用包和全部音色，保留音色偏好、其他系列和历史。

权重 Apache-2.0；完整许可证随包安装。运行时不依赖用户 Python；固定官方二进制在构建时校验并内嵌。运行时及第三方许可证随应用打包。Piper 继续作为按语言下载轻量音色包的另一个系列。

## 验证范围

本机 macOS Apple Silicon：原生 CPU 实测 HY Q4 英→中、英→法、日→英；Kokoro 七种语言均输出有效 WAV。实测短句 HY 冷启动约 6.5 秒，后续短句约 0.2 秒；Kokoro 短句约 1.3–2.7 秒。以上是本机样例，不是其他机器的速度承诺。

Q8 已固定官方文件和校验和，但本次未下载真实 Q8 权重测试；每次安装仍需通过原生推理自检才能就绪。Linux x64/ARM64、Windows x64 有固定运行时资源，但本轮没有真机验证。Intel macOS 未真机验证；其 Piper 后端仍不提供，HY-MT/Kokoro 的实际加载也以运行时检查为准。没有运行时资源的平台不会伪报支持。

自动验证与桌面交互的最终结果随本次完成报告记录。原型 HTML 的模拟进度不能当作测试证据。
