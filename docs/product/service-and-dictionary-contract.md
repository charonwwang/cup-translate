# 服务与词典功能交互规范

实施状态：对应 P1 修复已合并到本地 master；版本发布及外部环境验收状态见 [合并与验证结果](../reviews/service-capabilities-2026-10-26/INTEGRATION.md)。

维护对象：Cup 翻译服务、语音服务、收藏连接、插件与词典补全。建立日期：2026-10-26。本文定义后续实现应遵守的目标行为；3.0.13 的已知偏差与实施状态见 [问题评审](../reviews/service-capabilities-2026-10-26/README.md) 和 [执行计划](../reviews/service-capabilities-2026-10-26/EXECUTION.md)。其他模块保持现有行为，修改前需补充对应规范。

## 产品词汇

| 名称 | 用户理解 | 例子 |
| --- | --- | --- |
| 翻译引擎 | 负责把原文变成译文 | Google、HY-MT |
| 词典 | 提供词条资料，可能包括音标、例句和录音 | 在线词典、离线词典包 |
| 语音服务 | 负责把文字读出来 | 本地系统语音、Qwen、Piper、Kokoro |
| 后备朗读服务 | 翻译引擎无自带朗读时使用的服务 | HY-MT 结果使用 Qwen |
| Anki 连接 | 把当前内容发到用户自己运行的 Anki | 本机 AnkiConnect |
| 术语表 | 用户指定翻译中应使用的术语 | 产品名、专业名词 |
| 历史记录 | 查阅以前的翻译记录 | 翻译历史列表 |
| 收藏与导出 | 明确保存词条到指定目标 | 添加到 Anki |
| 插件 | 扩展某一类服务的代码与资源包 | `.potext` |

术语表不等于生词本；历史记录不等于收藏；模型下载完成不等于服务启用；音标不等于音频。界面不得用同一名称暗指多种功能。

## 页面与模块责任

| 页面或区域 | 主任务 | 入口与返回 |
| --- | --- | --- |
| 翻译结果卡 | 展示译文、词条资料、来源及操作 | 划词或输入后出现；展开、折叠、切换引擎 |
| 服务设置 | 管理已配置服务、顺序、启用和删除 | 设置页；添加后回到列表并显示结果 |
| 模型与连接 | 管理本地资源与运行环境 | 从服务设置或设置导航进入同一能力管理器 |
| 语音配置 | 选择后备服务、音色和试听 | 结果卡或设置页进入，关闭回到原入口 |
| 收藏与导出 | 配置目标连接，说明外部依赖 | 用户点收藏时可引导配置，返回后保留当前结果 |
| 插件管理 | 发现来源、安装包、添加服务实例与卸载 | 服务设置进入；先安装，再配置并启用 |

一个资源管理器只能有一个 Modal 所有者。跨入口复用内容和控制器，避免配置对话框中再嵌套完整配置对话框。需要更复杂步骤时在同一容器切换步骤，并提供明确返回路径。

## 翻译结果卡

原文、译文、词典补充资料和音频来源分别表达。主译文完成后，词典查询失败不能让整个卡片变成翻译失败。模型生成释义或音标必须标注“模型生成”，无法确定的音标留空。

英语单词可显示词性、音标、例句；中文词语使用词语或文本视图，有可信拼音时展示拼音。短语和句子优先展示译文与用法，不出现强制音标缺失警告。无空格只能作为分类线索，不能作为跨语言单词判据。

| 内容状态 | 展示 | 可操作项 |
| --- | --- | --- |
| 主翻译请求中 | 加载状态 | 停止或更换输入 |
| 主翻译成功，词典未知 | 完整译文 | 朗读、复制、收藏、主动查词典 |
| 无词典音标 | 适用于英语单词时轻量提示 | 有 TTS 即可朗读原文 |
| 查询词典中 | 补全区域显示查询中 | 原译文继续可用，换词取消旧请求 |
| 词典无词条 | 显示无词条，保留现有内容 | 重试或选择其他来源 |
| 词典失败 | 补全区域显示简短原因 | 重试，不重发主翻译 |
| 设备内模式 | 明确显示联网补全受限 | 可用的本地词典和本地 TTS |

“朗读原文”读取当前原文与源语言；“朗读译文”读取当前译文与目标语言。不能朗读缺失的 IPA 字符串来代替文字发音。若词典有地区录音，使用对应录音；若只有 IPA，TTS 按原文合成并标明实际服务，不能把通用合成冒充英式或美式真人录音。

## 语音添加与模型管理

标准路径为：选择语音能力 → 检查资源或连接 → 必要时安装 → 试听 → 保存配置 → 显式启用。对无须安装的服务跳过安装步骤，页面说明所需条件。

Qwen 第一阶段保持单例。模型规格和默认音色归全局 Qwen 配置，重复添加时打开已有配置。下载任务关闭后可继续，编辑草稿关闭后不保存。

| 按钮 | 精确定义 |
| --- | --- |
| 测试或试听 | 执行一次验证或播放，不保存、不启用 |
| 保存配置 | 持久化草稿，保持既有启用状态 |
| 保存并启用 | 保存成功后显式加入可用服务或切换后备策略 |
| 取消或关闭 | 放弃未保存编辑，不持久化，不切换策略 |
| 关闭并后台安装 | 只关闭任务窗口，后台安装继续 |
| 释放内存 | 停止模型推理进程，模型文件与配置仍保留 |
| 移除服务 | 移除服务引用，提示受影响的朗读策略 |
| 删除模型 | 删除资源文件，说明影响并处理正在运行任务 |

朗读待机时显示喇叭，加载或合成时显示等待状态，播放时可停止。一个窗口同一时刻只播放一个语音；切换词条、播放其他内容或关闭时停止当前播放。失败提示提供配置或重试入口，不能只出现空白窗口。

## Anki 连接与收藏路径

首次进入先说明：Cup 提供 Anki 连接，需要用户自己的 Anki 桌面应用和 AnkiConnect。端口默认 8765，可修改；API key 放高级设置。

测试连接为只读，不创建测试词条或牌组；保存不依赖 Anki 正在线上。未启动时可以保存为“已保存，尚未连接”。点击收藏才写入 Anki，默认显示目标牌组。

| 收藏状态 | 反馈 |
| --- | --- |
| 未配置 | 配置目标；返回后保留当前词条 |
| 连接不可用 | 启动 Anki 与 AnkiConnect 的指南、重试 |
| 正在添加 | 禁止同项重复点击，显示进度 |
| 已确认添加 | 明确成功，可显示已添加状态 |
| 重复词条 | 提示已存在，不当作新增成功 |
| 服务拒绝 | 展示可理解原因与配置入口 |
| 响应超时且结果未知 | 提示先检查 Anki，避免自动重发 |

收藏成功与否由 Anki 的响应决定，不由 HTTP 200、配置已保存或按钮被点击决定。词条没有音标或音频时，仍可收藏文本。收藏操作不自动下载词典、不自动替换翻译结果、不自动生成额外 TTS 音频。

## 插件生命周期

插件目录仅帮助发现来源，兼容状态需要 Cup 自己验证。下载包、安装成功、添加服务配置、启用和执行成功是五个不同阶段，分别展示结果。

安装前显示来源及插件类别，失败显示包名和原因；批量安装逐包报告。添加服务时展示所需配置及外部条件。重启后已保存实例可恢复。移除实例和卸载包分开：一个包存在多个实例时，卸载前说明影响并统一处理引用；卸载失败不谎报完全成功。

产品默认支持 `.potext` 本地导入。自定义插件沿用宿主协议。npm 仅可作为插件作者的构建工具，当前不作为应用安装入口。第三方目录标签和“官方”字样不能使用户误认为该插件由 Cup 维护。

## 隐私与数据来源

用户可区分本地翻译、本地合成、联网词典、联网音频与外部收藏。联网补全展示服务名称和发送原文的事实，设备内模式禁用联网路径。来自模型、词典或翻译引擎的资料分别标注，不能把联网补充包装成模型离线能力。

插件的权限声明必须与宿主实际约束相符。无法受设备内策略约束的插件，在该模式下不得运行。密钥不进入默认日志、错误 Toast、截图文案或普通配置导出。

## 交互一致性与可访问性

保存、测试、启用使用不同按钮文案。保存和测试过程中避免重复提交；错误保留当前输入。短错误内联显示，详细技术信息折叠且可复制。错误不是瞬间消失的大段 Toast。

弹窗打开后焦点进入首个合理控件；Tab 不穿透遮罩；关闭后焦点返回触发按钮。键盘关闭遵守与普通关闭相同的草稿规则。窄窗口、暗色模式和系统字体放大下按钮与错误详情仍可访问，长错误不能覆盖保存和取消操作。

## 后续变更规则

每次功能修改先确认它属于哪个模块，列出受影响入口、状态、持久化字段、失败与恢复行为，再修改代码。跨模块能力通过明确接口连接，不借同名按钮或全局副作用连接。

PR 至少写明用户触发路径、前后行为、配置兼容、隐私变化及验证证据。涉及本规范的变更同步更新对应章节；实现未完成时保留执行计划中的待办，不把设计描述改成已经验收。

优先级冲突时遵循：用户当前明确要求 → 已验收的功能契约 → 本轮目标设计 → 有日期的历史研究或路线。`docs/MAINTENANCE.md` 中旧的默认关闭、平台优先级等陈述须经核对后更新，不应被当作无需评审即可删除当前能力的授权。

## 模型管理弹窗与存储操作（2026-10-26 实测反馈修订）

所有服务配置和模型安装弹窗必须在设置窗口入口加载样式，不能依赖用户先访问“模型与连接”。选择器采用同一套浅色/深色卡片、边框、输入框、焦点环和按钮规则。取消/关闭为中性操作，仅删除和放弃修改使用危险语义。内置翻译、OCR、语音及收藏选择器应先关闭再打开配置，避免叠层。

安装步骤是有语义的选择、检查、安装三步列表，当前步骤标记 `aria-current=step`，已完成步骤显示勾选。安装完成的 Qwen 管理器展示文件就绪及规格体积，同时独立展示运行状态：未加载、加载中、合成中、已加载可复用。已下载模型不因“保存”再次下载，也不能把服务列表中出现配置当作下载进度。

| 操作 | 预期结果 | 明确保留的内容 |
| --- | --- | --- |
| 试听音色 | 优先播放已验证样音；其他音色第一次生成后缓存，停止时阻止迟到播放，待合成时还会结束推理进程 | 配置、模型文件 |
| 测试实时合成 | 明确绕过样音文件，合成短句；保留进程供后续朗读使用 | 配置、模型文件 |
| 释放内存 | 停止本应用播放、结束 Qwen 推理子进程并反馈完成；下次朗读重新加载 | 模型文件、依赖环境、配置 |
| 删除模型文件 | 先确认，再移除此规格应用自有模型和样音；共享目录只解除安装登记，绝不删除共享权重 | 另一规格模型、Python 环境、服务配置 |
| 保存 | 更新音色和服务配置；勾选“保存后启用后备朗读”才修改后备策略 | 已有模型和当前未显式修改的策略 |
| 关闭/X/Esc | 有草稿时确认放弃；没有草稿直接关闭；不会隐式保存 | 上次已保存的设置 |

Qwen 底部只保留关闭、保存和后备朗读勾选项。试听紧邻音色选择；实时合成、规格切换、释放内存及删除放在“模型与存储”折叠区。执行释放/删除期间禁用重复操作与关闭；失败保留草稿、显示详细原因并允许重试。

推理进程缓存最多八条短音频、合计最多 8 MB，退出或释放内存即清空。任意用户朗读文本不写入磁盘缓存；磁盘只保留固定试听样音。样音按规格、音色、固定模型修订区分，读取时校验 PCM 格式和非静音采样。前端进入播放前再次恢复 AudioContext，长时间等待后仍能启动播放。

## 朗读内容绑定与兼容推理

播放成功必须同时满足当前内容身份与音频有效性。切换词条、语言、服务或请求版本后，旧结果不得继续播放。Qwen 私有协议携带请求编号、文本摘要、语言和音色，缓存命中同样绑定当前请求；验证失败时丢弃，不能播放上个请求或固定样音。

本轮 Mac 默认使用 CPU 兼容推理，线程限制为 1–4；已有 MPS 安装无需重装，首次启动自动迁移实际设备记录。此选择源于本机对 MPS/float32 内容错配的真实复现。英文单词采用确定性生成与有限音频预算，失控生成不能作为成功缓存。试听的固定样音仅限设置页专用预览命令，结果页必须合成用户实际点击的内容。
