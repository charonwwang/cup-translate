# 桌面实机验收清单

登记：2026-11-12。下列项目全部待做。Windows / Linux 设备暂不可用，Anki / 欧路实际写入尚未执行。Actions 的结果只登记为构建验证；既有 Apple Silicon 验收记录见 [v3.0.14 交付证据](../reviews/service-capabilities-2026-10-26/RELEASE-3.0.14.md)。

每轮记录提交、应用版本、安装包 SHA-256、系统版本、CPU 架构及桌面环境。使用专门的系统用户或快照与合成测试数据，禁止覆盖日常配置、历史或凭证。每个平台/架构单独登记；无设备、签名包、测试源或账号时保留待做，并记下缺项。

| 状态 / 项目 | 设备或账号要求 | 操作步骤 | 通过标准 |
|---|---|---|---|
| 待做 · Windows 安装与启动 | 对应 x64 / x86 / ARM64 的 Windows 设备或原生架构测试环境、测试用户、对应 NSIS 包及可用 WebView2 | 在干净环境运行 NSIS 安装；从开始菜单启动；打开设置与翻译窗口；退出并再次启动 | 安装无错误；桌面入口、托盘和窗口可用；完成一次测试翻译；重启后仅一个实例 |
| 待做 · Windows 应用内升级 | 上述设备，公开 v3.0.14 安装包、由兼容公钥验签的候选更新包和隔离更新源 | 安装旧版，写入一项设置和几条合成历史并记录基线；应用内检查、确认更新并等待重启；再次检查设置、历史和翻译 | 旧版识别候选版本，验签、安装和重启成功；实际版本正确；应用标识、设置及历史内容一致；翻译仍可用 |
| 待做 · Linux 安装与启动 | 对应 x64 / i686 / ARM64 Linux 设备；目标发行版的测试用户、依赖及对应 DEB / RPM；另在提供 AppImage 的目标验证 AppImage | 分别在对应发行版用包管理器安装 DEB / RPM；从桌面菜单启动并验证设置和翻译；在干净测试用户下单独启动 AppImage | 安装时依赖可解析；桌面入口、托盘（具备托盘的桌面）、设置和翻译可用；退出后可重新启动 |
| 待做 · Linux 应用内升级 | 受支持目标上的 v3.0.14 AppImage、可写路径、兼容签名的候选 AppImage 更新包、隔离更新源 | 从 AppImage 启动旧版，写入合成设置和历史；应用内检查、下载、安装并重启；核对 AppImage 和应用内版本、设置与历史 | AppImage 完成验签并自替换，重启后版本正确且数据保留；DEB / RPM 由包管理器更新，不能以包管理器安装替代此项 |
| 待做 · Linux X11 桌面回归 | Linux 原生 X11 会话、编辑器、浏览器及本地翻译服务 | 确认 `XDG_SESSION_TYPE=x11`；在两个应用中分别选词并按全局热键；靠近显示器边缘重复 | 获取当前选区，快捷键触发一次，弹窗留在可见区域 |
| 待做 · 纯 Wayland 划词 | Linux 原生 Wayland 会话（记录 compositor 及版本），原生 Wayland 编辑器、浏览器及可用的本地翻译服务 | 确认 `XDG_SESSION_TYPE=wayland`，确认 Cup 与选词应用均未走 XWayland；在编辑器和浏览器选取合成短句，分别触发划词翻译并更换选区 | 每次都翻译当前选区，空选区不复用旧文本；无 XWayland 依赖；受限时记录具体应用与 compositor，不能记通过 |
| 待做 · 纯 Wayland 全局热键 | 同上，能配置 compositor 快捷键，记录权限/绑定方式 | 配置快捷键并把焦点放在原生编辑器和浏览器中，分别触发翻译、输入翻译；重启 Cup 后重测 | 不需 Cup 获得焦点即可触发对应操作，每次一次；重启后仍有效；冲突有明确提示或可诊断记录 |
| 待做 · 纯 Wayland 弹窗定位 | 同上，至少两屏并设置不同缩放；记录屏幕排列 | 依次在每屏中间、四角和屏幕接缝附近触发划词弹窗，再切换活动显示器重复 | 弹窗出现在触发所在显示器可见范围内，内容与控件可操作；记录定位与当前设计的差异，裁切或出现在错误屏幕判失败 |
| 待做 · Anki 写入 | Anki Desktop 独立且不连接日常同步的 profile、AnkiConnect v6，仅监听回环地址，独立凭证 | 保存配置并测试连接，比较牌组、模板、笔记计数；在 Cup 收藏带唯一标记的合成词条，检查 Anki 中的牌组、模板、正反面及启用时的音频；再次收藏并模拟写入结果未确认 | 保存和连接测试均不创建数据；首次确认写入一条内容正确的笔记；重复/结果未知有清楚提示，结果未知时不自动重发 |
| 待做 · 欧路词典写入 | 专用欧路测试账号、该账号的 OpenAPI Token、唯一测试生词本名称 | 保存配置并测试连接，确认没有新建生词本或词条；收藏一个标记过的英语测试词；从欧路端查看目标生词本及词条，再检查重复点击和结果未确认提示 | 连接测试只读；首次收藏按需创建目标生词本并确认词条写入，客户端不提交译文或音频；结果未知时不自动重发 |

升级前先用同一隔离环境验证拒绝签名不匹配的测试载荷，确认旧版仍可启动、配置和历史无变化。公开旧版内置正式更新地址；隔离验证可从 v3.0.14 源码构建仅替换更新地址的对照包，保留版本、应用标识和公钥，记录与公开二进制的区别。用对照包跑通不代表原公开安装包也已跑通。私有源与候选签名包另行准备；验证矩阵的无更新签名产物不能完成应用内升级。证据只保存脱敏截图、版本和摘要、配置语义差异及历史行数；清理时只删除测试标记的数据。
