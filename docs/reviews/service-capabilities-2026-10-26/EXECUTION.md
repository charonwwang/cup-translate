## 执行顺序和交付划分

| 批次 | 任务 | 依赖 | 完成标志 |

| 验收编号 | 场景 | 预期 |
| --- | --- | --- |
| A01 | Anki 未打开，保存配置 | 保存成功，标记未连接，不调用 addNote |
| A02 | Anki 未打开，测试连接 | 简短中文说明、启动指南、重试；无重复长堆栈 |
| A03 | 假服务返回 HTTP 200 + error | 测试或收藏失败，显示业务原因 |

| A05 | 在隔离 Anki profile 上测试连接 | 前后牌组、模型、笔记数量不变 |
| A06 | 首次收藏、再次收藏不同词条 | 正确建资源、note ID 可查，后续不重复建模板 |

| A08 | 收藏成功响应前超时 | 提示结果未确认，不自动再次写入 |
| A09 | 原文含 `<`、`&`、换行，无音频 | 卡片显示原文，未执行 HTML，无 null 音频项 |

真实写入用单独 Anki profile 和可识别测试牌组，不污染日常学习卡片。先记录笔记数，测试后按测试标记清理；不要直接删除用户已有 cup-translate 牌组。

本机可用下列只读命令检查连通性：

```sh
curl --max-time 3 --silent --show-error http://127.0.0.1:8765 -H 'Content-Type: application/json' -d '{"action":"version","version":6}'
```

带 API key 的测试从安全配置读取，不把密钥拼到终端历史或文档中。

| 测试样本 | 层次 | 通过要求 |
| --- | --- | --- |
| 自建离线确定性插件，四类各一个 | 全链路 | 安装、配置、启用、调用、返回值校验、卸载全通过 |
| 原样打包的上游 TTS 模板 | 安装与配置 | 点分 ID 可装载；HTTP 注入受控端点可正常合成并播放 |
| 上游翻译插件 | 执行 | 固定包版本和摘要，真实有效服务返回译文；失败归因于服务或宿主 |
| ECDICT 固定平台资源包 | 本地执行 | 包含所需数据和平台程序，真实查词返回释义与已有音标 |
| Anki 收藏模板 | 外部执行 | 隔离 Anki profile 中能收卡并核对内容 |
| 恶意或损坏包 | 拒绝路径 | 不写插件目录外，不覆盖当前可用版本，逐包错误可见 |

“HTTP 注入受控端点成功”只能证明宿主接口；外部 Lingva 等真实服务是否可用另列记录，不继承为端到端通过。ECDICT 资源包未准备齐时不能仅靠 `main.js` 运行就判定插件兼容。

清单每条必须含平台、Cup 版本、插件版本、包 SHA256、网络或凭证前提、测试日期、安装结果和执行结果。尚未实测的一律“未验证”，不得填满绿色。
