# 模型配置交互与 Qwen 试听回修

日期：2026-10-26，Asia/Shanghai。来自用户对已安装 3.0.13 修复版本的再次实测。本记录补充此前的 INTEGRATION.md，不能把前一轮只完成夹具的 Qwen 推理项目当成本轮真实推理证据。

## 问题与方案

1. 步骤粘连、按钮无样式：`models.css` 原本只在懒加载模型页导入。把资源管理器样式移到设置窗口入口加载，服务页直接打开也完整生效。统一服务选择和配置弹窗的间距、圆角、主次按钮、焦点环及浅深色配色。
2. 试听等待：原试听每次发起完整推理，模型加载和整段生成结束前都没有声音。新增独立样音命令：默认 Vivian 复用安装时真实合成的样音，其他音色生成一次并保存固定样音。读取时拒绝静音、截断和非法音频；不存在可用样音才生成。保留“测试实时合成”入口用于区分音色预览与推理性能。运行进程增加有大小上限的短音频缓存，加速重复单词，不把用户文本写磁盘。
3. 释放内存无反馈及下载语义混淆：后端公开独立运行状态；UI 同时显示模型文件体积与运行状态。释放按钮结束推理并显示完成消息；停止待合成试听同样发出原生终止命令。加入等待时间、有限的启动/预览超时，失败保留日志位置。
4. 按钮过多：底部只保留关闭与保存，后备启用改为显式勾选；试听紧邻音色；规格、实时测试、释放及删除移至折叠区。保存不触发安装。新增独立确认的模型文件移除，限制为本应用该规格权重，保留依赖环境、配置及其他规格；共享权重仅解除登记。

## 已完成的执行与验证

- 前端受 Git 管理测试：580 项通过。新增覆盖真实组件的待合成取消、释放反馈、确认删除及显式勾选启用；已有草稿、迟到响应、安装不隐式保存测试保持通过。
- Qwen Python：5 项通过，新增重复文本缓存、音色隔离、预览参数、容量淘汰覆盖。
- Rust 全量：198 通过，6 按原标记忽略；样音非静音/损坏校验、非法音色路径拒绝、应用自有文件删除、共享目录及符号链接保护、繁忙进程结束均有测试。
- 本机真实 0.6B MPS 模型：单独启动当前源码私有 worker，冷启动 10.96 秒，合成“你好。”7.12 秒，生成 2.40 秒 WAV，RMS 0.0934；相同输入第二次 0.0010 秒返回相同音频。进程在验证结束后正常退出。
- 已有安装验证样音：149804 字节，3.12 秒，峰值 0.6267、RMS 0.1099，确认为非静音 PCM16。
- 对照尝试 MPS bfloat16：本机短句生成没有稳定快于既有 float32，未把该实验精度变更纳入产品。没有将官方其他后端的流式延迟数字作为当前桌面程序性能承诺。参考 [Qwen 官方实现及推理说明](https://github.com/QwenLM/Qwen3-TTS)。
