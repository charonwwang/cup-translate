# Qwen3-TTS 应用内安装

Qwen 与 OPUS-MT、HY-MT、M2M-100、Piper、Kokoro 一样，使用“选择 → 检查 → 安装”三个独立步骤。第二步不下载模型或安装依赖；检查通过后进入第三步，再点击“开始安装”。高级设置中的下载入口也会回到模型向导。

## 下载内容与依赖

Qwen3-TTS CustomVoice 的 0.6B 模型文件约 2.50 GB，1.7B 约 4.52 GB，包含语音 tokenizer。两种规格都支持中、英、日、韩、德、法、俄、葡、西、意十种语言以及九种预设音色。

它比原生 Piper / Kokoro 需要更多依赖：Python 3.10–3.12、PyTorch、torchaudio、Transformers 4.57.3、accelerate 1.12.0、qwen-tts 0.1.1 与音频处理库等。新环境的依赖下载预计约 0.2–1.5 GB，安装后及缓存另占空间；缺少 Python 时还需下载 Python 运行时。检查页面分别展示模型、环境、额外依赖和磁盘预留。具体下载量随平台、所选环境和本机缓存变化。

应用自动处理全部安装与启动，不要求用户运行命令。采用普通 SDPA 推理，不需要额外编译 FlashAttention；本推理路径也不调用系统 SoX。Piper 与 Kokoro 使用应用内置原生运行时，不需要 Python 环境。

## 第二步：先检测再决定安装计划

1. 检测应用环境、当前虚拟环境 / Conda，以及常见位置的 Python。检查版本、依赖元信息及真实模块导入，不能只凭目录存在就认定可用。
2. 有完整兼容环境时优先复用，页面显示环境路径，不重复安装依赖。
3. 只有兼容 Python 时复用解释器，在应用数据目录创建独立环境，不修改系统或其他项目的 Python 包。
4. 没有兼容 Python 时，由应用通过 uv 自动下载受管理的 Python 3.12。uv 若已存在则复用，否则下载校验过的固定版本。不会修改用户 PATH 或要求安装 Homebrew。
5. 安装开始前再次检查所选环境和可用磁盘，防止检查结果过期。

## 第三步：安装、校验与真实合成

下载固定 revision 的官方模型文件，复用完整且经校验的已有 Hugging Face 缓存。权重通过 SHA256 校验。中断下载保留部分文件以便重试。只有真实生成测试 WAV 后才写入“已安装”记录；依赖下载成功或目录存在都不足以标记安装完成。

安装过程可关闭窗口继续；重新打开后显示后台任务。失败有错误信息与日志位置。可取消安装并保留缓存，再重试。

## 朗读与进程管理

应用按需启动私有子进程，以标准输入 / 输出交换 JSON 和 WAV，无需本机 HTTP 服务或端口配置。GPU 使用经过验证的精度；实际合成失败会释放 GPU 模型并自动尝试 CPU，成功后记录实际设备。模型进程会复用，切换规格会释放旧进程。“从内存卸载”会结束推理进程，应用退出也会结束它。推理阶段只使用本地权重并启用离线模式，不发送原文给外部语音服务。

Google / Lingva 仍优先使用自身朗读；Qwen 是没有自带朗读服务的后备选项。

## 来源与范围

- Qwen 模型及推理库：[QwenLM/Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)，Apache-2.0。
- 自动 Python 管理：[Astral uv](https://docs.astral.sh/uv/guides/install-python/)。uv 自身为 MIT / Apache-2.0；Python、PyTorch 等依赖遵循各自许可证，不统称为模型许可证。
- 固定模型 revision、文件尺寸与权重摘要、uv 安装器摘要记录于 `src-tauri/resources/qwen-models.json`。
- 当前适配 macOS ARM64、Linux x86_64 / ARM64、Windows x86_64；其他平台会提前提示不支持。实际运行验证记录另行说明，不将平台适配声明等同于逐平台实测。

## 本机验证记录（2026-10-22）

- macOS ARM64、16 GB 内存；应用 3.0.13。检测并复用了已有 Python 3.12.15，为应用创建专用环境，实际安装 PyTorch / torchaudio 2.9.1、Transformers 4.57.3、accelerate 1.12.0、qwen-tts 0.1.1。
- 从应用内启动并实际下载了 0.6B 的全部 2,498,383,610 字节文件，校验通过。初次 MPS FP16 合成出现 NaN，未写入安装成功标记；改为 MPS FP32 后真实合成成功。CPU 自动回退与释放 GPU 对象的顺序另有单元测试覆盖。
- 同一个私有工作进程分别生成了英文 Ryan、中文 Vivian、日文 Ono_Anna 的 24 kHz 单声道 PCM16 WAV，格式、时长、峰值及非静音检查通过。记录和音频位于 `docs/research/evidence/qwen-managed-0.6b-*`。

| 语言 | 输出时长 | 合成耗时（不含首次加载） |
| --- | ---: | ---: |
| 英语 | 6.72 秒 | 18.45 秒 |
| 中文 | 5.04 秒 | 11.39 秒 |
| 日语 | 5.28 秒 | 12.17 秒 |

首次加载约 10.39 秒。这是本次机器和示例文本的实测，不能视为所有设备的速度保证。1.7B 在此轮仅做目录与安装计划适配，未实际下载或验证合成；Linux / Windows 也未在本轮实机验证。
